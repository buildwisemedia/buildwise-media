03 · The operating rule

Same machine work, two economics — a different lever on each

Flat-rate seat · GPT‑5.6 “Sol”
Run it hot.
The lever is utilization.

The seat is prepaid, so every task it runs is free at the margin — waste is an idle queue, never a spent dollar. 719 runs is a floor, not a ceiling: only 15 were design classes, the heaviest work on the clock.
