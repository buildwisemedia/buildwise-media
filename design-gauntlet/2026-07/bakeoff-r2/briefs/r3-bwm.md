# Design Dispatch Brief — ROUND 3: The Buildwise Media Rebrand. You are competing for the job.

One-pass build. There is no follow-up round. Judged blind against two rival builds.

## The assignment
Buildwise Media's owner is tearing up the current site. Rebuild the homepage as a SALES PAGE. You keep exactly TWO things from the old identity — everything else is yours to reinvent:
1. **Signal yellow `#F0FF00`** — the color the company is known for. Use it however you want: dominant, accent, weapon.
2. **The logo** (real SVGs below — embed as given). Exception for legibility: on light backgrounds the wordmark text fills may go dark neutral; the yellow dots/gradient of the mark stay exact.

Light mode is explicitly allowed. Any type system, any layout language, any graphics, any register. Ignore the current site, or glance at it only as the thing you're replacing.

## Output contract
- ONE complete, self-contained HTML file. CSS inline; vanilla JS inline; Google Fonts `<link>` allowed, nothing else external. Photo areas = art-directed placeholder surfaces with intent captions (no fake photos). Fully responsive.
- Copy: use ONLY the fact sheet below. No other stats, no invented client names or testimonials (placeholder testimonial layout is fine, clearly placeholder). Reading level: plain English, roughly 5th–7th grade. Voice: "we / the Buildwise team + our AI system" — never a single named founder; no founder photo or bio.
- Never show a price alone: any price appears WITH what it replaces (the anchor in the fact sheet).
- Never name third-party software vendors or platforms.

## FACT SHEET (the only claims allowed)
- Category: verifiable custom AI systems for service businesses. We build an AI growth system on the client's own domain, run it for them, and the asset stays theirs.
- Promise register: "You run the business. The system makes you the most-chosen name in your market." Outcomes are verifiable — the client can see every lead, call, and job the system produced.
- Who it's for: owner-led US service businesses (think home services: heating-and-air, plumbing, and their neighbors) whose owner is the bottleneck; skeptical because agencies burned them before. Do NOT show revenue numbers or qualification thresholds.
- The trust anchor: "it actually works" — shown, not claimed: live systems, real leads, weekly numbers the client reads.
- Offer structure: Ascend — $15,000 one-time install + $7,000/mo, true month-to-month after the first 90 days, no long contract, no exit penalty. Entry: Ascend Pilot — $15,000, 45 days, the install is the deliverable. Top tier: Ascend Pro — $25,000 install + $15,000/mo, limited per territory.
- Price anchor (required whenever a price shows): the system replaces the stack an owner otherwise assembles — an agency retainer, a website vendor, a booking tool, an answering service, ad management, and a part-time marketer — one system instead of six invoices.
- Timeline: live in 30 days.
- Primary CTA: "Get My Free Revenue Leak Map". Secondary CTA: "See the System" (anchor link down-page). Booking path: /book.

## Hard bans (the generic-AI-slop devices — your rebrand must not be these)
1. Rounded/geometric display sans ≥800 as display voice · 2. default coral/red accent · 3. decorative arc clutter · 4. rotated sticker/stamp devices · 5. ghost numerals · 6. number-in-circle step cards · 7. autoplay media, popups.

## Craft bar
This is a pitch for a rebrand contract. Judged on: does it feel like a NEW company (not a reskin), does yellow+logo carry recognition, does the sales page actually sell (clear promise → proof register → offer → one obvious next step), typographic craft, and conversion clarity for a skeptical owner reading on a phone at night.
